Get Blink into the app

  1. Open Home Assistant and create your account
  2. Settings → Devices & services → Add Blink
  3. Profile → Security → create a Long-Lived Access Token
  4. Portainer → stack homepulse → set HA_TOKEN → update stack / restart home-registry
  5. Refresh HomePulse /app/ — Blink cameras appear under Home Assistant
