# Lumen — Lightroom-style mobile photo editor

## Android APK

Download and install:

**[`releases/Lumen-release.apk`](releases/Lumen-release.apk)** (~46MB)

Package id: `app.lumen.edit`

Enable *Install unknown apps*, then open the APK on your phone.

## Source / web

```bash
cd lumen-edit
npm install
npm run web
```

See [lumen-edit/README.md](lumen-edit/README.md) for features, Lightroom preset import, and rebuild steps.
