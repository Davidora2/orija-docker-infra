# MeshRelay

React Native (Expo) app for **phone-to-phone mesh messaging** — relay chat through nearby devices over Bluetooth / Wi‑Fi when there’s no internet.

See **[mesh-relay/README.md](./mesh-relay/README.md)** for setup, architecture, and how to enable real BLE on Android & iOS.

```bash
cd mesh-relay
npm install
npx expo start
```
